# Tetris Game Documentation

## Overview
This repository contains a browser‑based implementation of the classic **Tetris** game written in vanilla HTML, CSS and JavaScript.

The documentation is split into several Markdown files within the `doc/` directory so that each topic can be explored independently:

- `overview.md`: High level description of the project and its goals.
- `architecture.md`: Detailed explanation of the code structure, modules and data flow.
- `milestones.md`: Development plan derived from the blueprint – what was built when and why.
- `algorithms.md`: Core algorithms (matrix rotation, collision detection, line clearing).
- `style-guide.md`: Coding conventions, naming scheme and folder layout.
- `resources.md`: External references used during development.

All these files are linked from a single `doc/index.md` entry point for quick navigation.
